# Towards Sustainable Artificial Intelligence:
## Energy-Efficient Deep Learning Models for Intrusion Detection Systems


## Overview

This undergraduate thesis investigates energy-efficient
deep learning approaches for intrusion detection systems.

The research focuses on optimizing model performance,
energy consumption, and retraining efficiency under
changing network environments.


## Research Motivation

Deep learning models provide high predictive performance,
but their computational requirements increase energy
consumption.

This research explores sustainable AI approaches
for reducing energy cost while maintaining detection
performance.


## Research Objectives

1. Develop IDS models using machine learning and deep learning.
2. Compare Random Forest with DL architectures.
3. Analyze energy consumption of different models.
4. Investigate energy-efficient retraining strategies.
